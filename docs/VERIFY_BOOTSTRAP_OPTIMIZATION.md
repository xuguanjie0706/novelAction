# Bootstrap 优化验证指南（2026-05-06）

本文档用于验证「一句话生成（Bootstrap）」阶段的 P2 优化是否真正生效。

## 验证目标

1. **genre_kit 全流程注入**：Bootstrap 所有步骤是否都正确读取了流派手册（开局节拍、禁忌反例、配角配额、对白基调等）。
2. **speech_kit 可见性**：生成角色后，前端是否能正确展示结构化语风指纹。
3. **POV + 戏份预算可见性**：大纲章节节点是否能看到/编辑主要 POV 和戏份分布。

---

## 验证步骤

### 1. 准备两个测试项目（关键对比）

**项目 A（玄幻）**：
- 一句话创意：一个废柴少年意外觉醒上古血脉，从宗门底层逆袭成巅峰强者。

**项目 B（悬疑）**：
- 一句话创意：一个普通刑警在连环命案中发现凶手其实是自己的前妻。

**操作**：
- 分别用同一模型（推荐 Gemini）执行「一句话生成」。
- 生成完成后，进入「角色」和「大纲」页面进行对比检查。

---

### 2. 检查 genre_kit 是否生效（后端验证）

**方法 A：查看后端日志（推荐）**

在 `apps/backend` 目录下启动后端后，执行生成时观察日志：
```bash
cd apps/backend
uvicorn app.main:app --reload
```

生成过程中搜索日志中是否出现：
```
【流派编辑手册约束（必须严格遵守）】
```
或
```
【流派编辑手册约束】
```

如果 **_gen_characters**、**_gen_settings**、**_gen_storylines**、**_gen_power_systems**、**_gen_factions**、**_gen_key_skills**、**_gen_key_items** 这 7 个步骤的 prompt 开头都出现了上述内容，则说明注入成功。

**方法 B：前端对比检查（更直观）**

生成完成后，手动检查以下内容：

#### 项目 A（玄幻）应满足：
- 角色页：主角不应有“失忆”相关背景；至少有 2 个师长/势力角色；主角说话风格应偏热血直白。
- 大纲页：第一卷 phase 应为 `opening`，planned_chapters 建议 60；卷标题应带“宗门/血脉/逆袭”相关词汇。

#### 项目 B（悬疑）应满足：
- 角色页：配角配额应有较多“嫌疑人”角色；主角说话风格应偏克制、留白、多问句。
- 大纲页：第一卷应有明显“信息差”和“嫌疑人布局”感觉；章末钩子多为“新尸体/嫌疑人死亡/关键证据反转”类型。

**如果两个项目差异明显**，则 genre_kit 注入成功。

---

### 3. 检查 speech_kit 是否可见（前端验证）

**操作路径**：
1. 进入「角色」页面
2. 点击任意角色卡片 → 进入详情
3. 切换到「外貌风格」标签

**期望结果**：
- 「说话风格与口头禅」下方出现「结构化语风指纹」区块。
- 区块内应包含：
  - 标志性词语 / 口头禅（标签形式）
  - 句式偏好
  - 典型台词样本（可折叠列表）
  - 内心独白风格

**如果区块为空或不显示**，则前端渲染有问题或后端生成时 speech_kit 为空。

---

### 4. 检查 POV + 戏份预算是否可见（前端验证）

**操作路径**：
1. 进入「大纲」页面
2. 展开第一卷 → 找到任意「章」节点
3. 双击或点击右侧「编辑」打开详情面板
4. 切换到「章节要素」标签

**期望结果**：
- 出现「主要 POV」区块：可选择角色作为本章强制视点。
- 出现「戏份预算」区块：每个角色有滑块 + 进度条，可调整百分比。
- 保存后，重新打开应保留上次设置的值。

## 常见问题排查

| 现象 | 可能原因 | 排查建议 |
|------|----------|----------|
| Bootstrap 生成的角色说话风格都很像 | genre_kit 未正确注入到 `_gen_characters` | 检查 generation_service.py 第 1255 行附近是否有 `kit_block` |
| 前端角色页没有「结构化语风指纹」区块 | speech_kit 未渲染 | 检查 CharactersPage.tsx 中是否包含 `speech_kit && typeof` 判断 |
| 大纲章节节点没有 POV / 戏份预算 | 类型或表单未同步 | 检查 OutlinePage.tsx 中 NodeDetailPanel 的 form 初始化和保存逻辑 |
| 两个流派生成结果几乎一样 | genre_kit 只在 volumes 阶段注入 | 确认 `_get_genre_kit_block` 已加入所有 `_gen_*` 函数 |

---

## 验证通过标准

当以下条件同时满足时，视为本次优化验证通过：

1. 玄幻与悬疑项目在角色、设定、故事线、技能、道具上存在明显流派差异。
2. 角色详情页能正常展示结构化语风指纹（至少 signature_words 和 sample_dialogues）。
3. 章节节点能正常显示和编辑 POV + 戏份预算，且保存后数据不丢失。
