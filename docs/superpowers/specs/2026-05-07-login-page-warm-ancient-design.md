# NovelAction 登录页重新设计规范

**日期**：2026-05-07

---

## 1. 项目背景与目标

### 背景
当前登录页为居中卡片式设计，采用 indigo 冷色调，功能完整但缺乏“小说创作”的文艺沉浸感。用户希望通过重新设计强化以下三点：

- **文艺 / 沉浸感**：用户打开登录页即感受到古典小说创作氛围
- **简洁现代**：表单极简、无冗余元素、现代交互
- **品牌插图 / 动画**：增加视觉识别度与轻量微动效

### 设计目标
- 采用**左右分栏**布局（左插画 + 右表单）
- 建立**暖古风**配色体系（赭石、墨青、暖金）
- 提供高质量品牌插画与可维护的 CSS 动画
- 表单保持极简现代（浮动标签避免，固定 label + 清晰层级）
- 全程使用现有 Tailwind + React，无新增依赖

---

## 2. 整体布局结构

### 桌面端（≥768px）
- **左右比例**：左侧 55%（插画主导），右侧 45%（表单卡片）
- **左侧**：全高古风插画背景 + 径向渐变暗化层 `rgba(12,17,28,0.35)`（中心 → 边缘）
- **右侧**：半透明磨砂玻璃卡片
  - 背景：`#1C2526` + 70% 透明度
  - 模糊：`backdrop-blur-2xl`
  - 圆角：`rounded-2xl`
  - 内边距：`p-10`
  - 宽度上限：`max-w-[420px]`
  - 垂直居中 + 水平居中（在右侧区域内）
- **页面背景**：`#0C111C`（深青黑，比 slate-950 更暖）

### 移动端（<768px）
- 左侧插画自动变为顶部窄横幅（高度约 180px）
- 表单卡片改为全宽、居中、圆角保持 `2xl`
- 所有元素垂直堆叠，保持良好触摸目标尺寸

### Logo 与标题区域
- Logo：古风印章式 SVG（墨字或书卷），暖金描边
- 主标题：`NovelAction`（`Noto Serif SC` 或 Georgia 衬线）
- 副标题：`AI 驱动的古典小说创作空间`（小字、降低字重）

## 4. 字体与排版策略

- **Logo / 标题**：`Noto Serif SC`（或系统衬线，fallback `Georgia`）
- **表单正文**：系统 sans-serif（`-apple-system`, `Inter`）
- **Label**：`text-sm font-medium text-[#A8B0B8]`
- **输入提示**：`placeholder:text-[#5C5240]`
- **副标题小字**：适当降低字重与字号，增加行高

## 5. 品牌插图与视觉资产

### 插画内容描述
深夜书房一角：
- 木桌上有摊开的稿纸、毛笔、墨砚、油灯（灯火微黄）
- 身后隐约可见书架与竹帘
- 光源：仅油灯，右侧卡片区域自然偏暗

### 实现方式（优先级排序）
1. **首选**：Unsplash / Pixabay 高品质古风图 + CSS 滤镜（暖化、对比度微降、轻微暗化）
2. **备选**：SVG + CSS 动画实现的极简书房（油灯摇曳、墨水晕染）
3. **长期**：可考虑 Lottie 或 Canvas 轻量动画（需评估性能）

### 动画建议（CSS 级别）
- 油灯火焰：`animate-pulse`（2.5s 慢速）
- 墨水轻微扩散：`background-position` 循环（可选）
- 整体加载：`fadeIn_400ms_ease-out`

## 6. 组件详细规范

### 6.1 Tab 切换（登录 / 注册）
- pill 形状，背景 `#121B22`
- 激活态：`bg-[#C9A227] text-[#0C111C] shadow`
- 切换过渡：200ms ease-out 背景色
- 切换时清空错误提示

### 6.2 输入框
- 结构：上方固定 label + 输入框（6px 间距）
- 背景：`#121B22`，边框 `#3A2F2A`
- Focus：`border-[#C9A227] ring-1 ring-[#C9A227]/30`
- 注册用户名 label 后加灰色小字“（可选）”
- 密码框：右侧暖金眼睛图标（显示/隐藏）

### 6.3 提交按钮
- 满宽，`bg-[#C9A227] hover:bg-[#D4AF37]`
- 文字颜色：`text-[#0C111C] font-medium`
- Loading：暖金旋转图标 + “登录中…”
- 禁用：`bg-[#5C5240] text-[#8A7F6A] cursor-not-allowed`

### 6.4 错误提示
- 卡片式：`bg-[#3A2A2A]/60 border border-[#8B4A4A]/40`
- 左侧感叹号图标 `#D4A5A5`
- 150ms fade-in 动画

### 6.5 底部切换提示
- 文字：“还没有账号？立即注册”
- 链接色 `#C9A227`，hover `#D4AF37`
- Tab 切换时表单区域 `fade + slide-up`（200ms）

---

## 7. 微动画与过渡效果

- 所有交互元素：150–200ms 过渡
- 卡片首次加载：`animate-[fadeIn_400ms_ease-out]`
- Tab 切换：轻微 fade + slide-up
- 按钮 hover/active：颜色 + 轻微 scale（0.98）
- 左侧插画动画控制在 CSS 级别，避免重度 WebGL

---

## 8. 响应式与移动端适配

- `< md`（768px）：插画变顶部横幅，表单全宽
- 所有触摸目标 ≥ 44px
- 移动端表单元素间距适当增大

---

## 9. 无障碍与可用性

- 所有可交互元素保持 `focus-visible` 暖金 outline
- Tab 顺序：Logo → Tab → 输入框 → 提交 → 底部链接
- 错误提示同时提供 `aria-live` 区域
- 颜色对比度满足 WCAG AA（暖金在深底上对比度 > 4.5:1）

---

## 10. 实现注意事项

- **技术栈**：纯 Tailwind CSS + React Hook（`useState`），与现有 `LoginPage.tsx` 逻辑兼容
- **无新增依赖**：不引入 framer-motion、lottie 等
- **图片资源**：推荐放在 `src/assets/` 或使用外部 CDN（需配置 CSP）
- **主题切换**：当前仅实现暖古风，未来可扩展冷色 / 现代版
- **性能**：动画使用 `transform` 与 `opacity`，避免 layout thrashing
