## 章节正文写作链路概览（后端侧）

> **校对说明（2026-05-07）**：本文档由第三方分析后经人工复核修订。原版存在三处事实错误（AI 串行已改并行、Skill/Item 外键已部分实现、字数统计已处理 CJK+HTML）以及一处与当前阶段不符的建议（乐观锁/多人并发，系统尚无 auth）。已全部标注或删除。

### 关键痛点 & 优化建议

| 痛点 | 影响 | 推荐改进 |
|------|------|----------|
| **Skill/Item → Character 外键关联不稳定** | AI 偶尔输出名字而非 UUID，导致 `mastered_by_character_ids` 回退到名字匹配，名字拼写不一致时静默丢失关联 | Prompt 中明确禁止输出名字（仅允许 UUID），并在持久化层对非 UUID 字段做告警日志而非静默回退 |
| **场景层级调度缺失** | `Scene` 只有蓝图，章节正文写作时无结构化锚点，AI 生成方向感弱 | 在 `update_chapter` 时读取对应 `Scene`，将 `hook`/`conflict`/`goal` 自动注入章节 prompt payload |
| **Embedding 管线空白** | 记忆检索只能关键词匹配，语义相似度低，情节连贯性难保障 | 完成 `EmbeddingService.generate_embeddings`，在 `MemoryChunk`/`Scene`/`Chapter` 写入时同步生成向量；查询使用 pgvector `cosine_distance` |
| **ReaderPromise 深度闭环缺失** | 写章时承诺无法自动注入 prompt，复盘也不能自动检测是否兑现 | 写章 prompt 注入"本章必须/可以兑现的承诺"列表；章节保存后自动对比 `ReaderPromise.expected_chapter_window` |
| **一致性检查仅提示** | `consistency_issues` 需要人工逐条处理，效率低 | 区分"可自动修复"（如字段缺失、数字不对齐）与"需人工决策"（如情节矛盾），前者加确认后自动修复，后者高亮展示 |
| **快照存全文膨胀** | 每次快照存全文，百章后数据库版本表几十 MB 起 | 引入增量 diff 存储（如 `diff_match_patch`），仅存变更部分；或设置快照最大保留数，超出时清理旧版本 |
| **Bootstrap 多次 DB 写入** | 每步 AI 生成后立即写库，IO 频繁 | 无依赖步骤（Step 6–8 已并行）的结果可在内存中暂存，批量提交；错误回滚粒度需同步调整 |
| **LLM 速率限制无防护** | 高频 bootstrap 容易触发远程 API 限流，导致步骤失败 | `_call_with_retry` 加指数退避（`min 1s → max 32s`），并在 `_sequential` 层面限制同时在飞的并行调用数 |

### 推荐短期迭代路线（按优先级）

1. **Scene 三层调度打通**（最高优先级）  
   在 `update_chapter` 中读取对应 `Scene`，将 `hook`/`conflict`/`goal`/`pov_character_id` 注入章节起草 prompt，完成"章纲→场景→正文"链路。

2. **Skill/Item 外键约束强化**  
   Prompt 中去掉名字回退路径，持久化层对非 UUID 值记录告警日志；补充集成测试验证 UUID 命中率。

3. **Embedding 管线实现**  
   `EmbeddingService` 完成批量向量化，`MemoryChunk` 写入时同步生成；先用本地 `bge-large` 或 OpenAI `text-embedding-3-small`，通过 pgvector `cosine_distance` 实现语义记忆检索。

4. **ReaderPromise 写章注入**  
   写章 prompt 查询 `expected_chapter_window` 覆盖当前章号的 `ReaderPromise`，分"必须兑现"/"可兑现"两级注入；章节保存后自动更新 `status`。

5. **快照存储优化**  
   引入 `diff_match_patch` 增量存储，或设置每章最多保留 N 个快照，降低数据库膨胀速度。

6. **LLM 限流防护**  
   `_call_with_retry` 加指数退避；`_sequential` 并行分支加 `asyncio.Semaphore(3)` 限制并发 AI 调用数。

### 长期愿景

- **情节连贯度评分**：章节保存后自动触发质检，给出 0–10 连贯度分数，作者可直观看到章节流畅程度。  
- **章节–场景–记忆闭环**：三层调度（章节→场景→pgvector 记忆检索）全链路贯通，AI 写章时自动拉取相关记忆片段。  
- **读者承诺实时对比**：`ReaderPromise` 与章节进度实时比对，未兑现承诺自动生成提醒。  
- **编辑后置审校**：章节保存后自动触发 AI 质检（`quality_debts`），UI 展示可修复建议，实现"写完即审"。
