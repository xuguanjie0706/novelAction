## 空状态契约（FR-004）

对 **S-01～S-05** 中任一「列表/树为零条」视图：

- **MUST** 展示：一句 **情境化中文** 说明（非裸「暂无数据」）。  
- **MUST** 展示：**一个**主行动（Button 或明确文字链），指向创建、打开向导或合理跳转。  
- **SHOULD**：次行动不超过两个，避免选择瘫痪。

## 加载与失败契约（FR-005）

- **MUST**：异步拉取主要列表时存在 **可见加载指示**（spinner、skeleton 或文案「加载中…」之一）。  
- **MUST**：请求失败时展示 **人类可读** 原因 + 建议下一步（重试 / 检查网络）；不得仅展示裸 HTTP 状态码。  
- **SHOULD**：加载完成前后 **主布局骨架不变**，避免大块跳动（与用户故事 3 对齐）。

## 编辑区契约（FR-003、FR-008）

- **MUST**：正文区域有 **明确最大行长**（实现为 `max-width` + 水平居中或等价手段）。  
- **MUST**：`ProseMirror` 内背景/纹理 **不得** 使正文与背景对比低于走查认可的阅读基线。  
- **SHOULD**：段落行高、标题与正文 **至少一种** 区分手段（字号 / 字重 / 间距）。

## AI / 队列契约（FR-006）

- **MUST**：AI 面板首屏在 **5 秒内** 可扫读到「能做什么」与「与当前上下文的关系」（标题/副标题/分区标签择一或以上）。  
- **MUST**：队列中状态 **视觉可区分**（至少图标+文案或颜色+文案之一组合，且不完全依赖色相）。

## 验收引用

成功标准 **SC-002～SC-003** 可直接用本文件 **表面清单** 与 **空状态契约** 生成检查表勾选项。
